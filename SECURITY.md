# Security policy

## Report privately

Please do not open a public issue if you find:

- patient-identifying information or DICOM/burned-in identifiers;
- a fabricated or mismatched citation, DOI, PMID, guideline, or source;
- a drug, dose, threshold, algorithm, or clinical default that could be reused unsafely;
- incorrect medical arithmetic or chart geometry;
- a dependency, installer, browser, or file-handling vulnerability.

Use GitHub's private security advisory workflow for this repository. Describe the affected file and safe reproduction steps without including patient data, credentials, unpublished manuscripts, or confidential institutional material.

This repository is a presentation-generation aid, not clinical decision support. Automated validation reduces known failure modes but does not certify a deck for clinical or academic use.
