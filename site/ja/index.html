How it works

3つのステップ。真ん中はジェネレーターではなくゲートです。

依頼する

論文、アブストラクト、メモ、表、CSV を渡して、どんな発表かを伝えます。発表形式・言語・聴衆・時間は Skill が判断します。

安全ゲートを通る

PHI、引用、統計、画像権利、COI、倫理の項目を検査。検証できないものは SOURCE NOT PROVIDED のまま残り、最終状態をブロックします。

発表する

同梱の localhost サーバーでブラウザ発表するか、1スライド1ページの PDF に印刷。どの時点でもインターネットは不要です。

Use cases

医師が実際に行う発表のために設計しています。

抄読会

このRCT論文を、15分の日本語抄読会スライドにして。PICO、バイアスリスク、適用可能性を重視。

PICO を先に固定し、効果推定値は区間とともに読む。原資料がない確実性は「未評価」のまま明示されます。

学会発表

この結果を15分の英語学会発表スライドにして。主要アウトカムは Forest プロット、生存解析は Kaplan–Meier、Table 1 は投影チェックを通る水準で。

決定論的チャートは、検証済みの1つのデータオブジェクトから幾何とラベルを導出します。手配置の数値はありません。

症例カンファレンス

この匿名化メモから10分の症例カンファレンスデッキを作って。タイムラインと鑑別選択スライドを入れて、不確実性は明示して。

選択コンポーネントはキーボード操作可能で印刷安全。PHI の懸念があれば、議論ではなくビルドを停止します。

教育講演

研修医向けに、敗血症の初期対応の教育スライドを作って。アルゴリズムとクイズ形式の確認問題つきで。

アルゴリズム、チェックリスト、クイズスライド。回答状態は色なしでも明示されます。

Safety gate

Skill は不足した医学的事実を「補完」せず、停止します。

このプロジェクトは医療者向けの学術・教育プレゼンテーションを作るものです。患者向け資料、診断、治療選択、臨床意思決定支援ではありません。

ゲート 動作
PHI 患者識別情報の可能性がある場合（DICOM メタデータや画像への焼き込みを含む）、修正または匿名化された入力を求めて停止します。
引用 引用、DOI、PMID、ガイドライン版が検証できない場合、最終状態をブロックします。文献を捏造しません。
数値 分母、パーセント、単位、信頼区間、p 値、フロー合計の矛盾をプレビュー前に検出します。
COI・倫理 COI を既定で「なし」、倫理を既定で「承認済み」にしません。未回答の必須項目は 未確認 / SOURCE NOT PROVIDED のまま残ります。
画像 来歴、ライセンス、同意、許可が不明な画像は使用しません。
合成コンテンツ カタログと実例の全スライドに恒久的な可視マーカーがあり、エビデンスとして再利用できません。

Install

クローンから最初のデッキまで、3分。

01

リポジトリをクローン

git clone https://github.com/kgraph57/medical-slide-templates.git
cd medical-slide-templates
02

Claude Skill として導入

node scripts/install-skill.mjs --dest "$HOME/.claude/skills/medical-slide"
03

自然文で依頼する

# このRCT論文を、15分の日本語抄読会スライドにして。
# この匿名化メモから10分の英語症例カンファレンスデッキを作って。

Author

午前2時のスライド作業にうんざりした、現役小児科医が作りました。

Medical Slide は、学会発表や抄読会のための個人ツールとして始まりました。医師が実際に行う発表を、実際の時間制約の中で作るためのツールです。

安全ゲートがあるのは、自信満々なシステムが生成する医療コンテンツが現実のリスクだからです。このプロジェクトは、不足した事実を補完するより、停止し、印をつけ、尋ねることを選びます。

岡本賢は小児科医で、AI 医療起業家です。臨床実践と応用 AI の交差点で、執筆・教育・ツール開発を行っています。
