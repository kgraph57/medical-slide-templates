抄読会

このRCT論文を、15分の日本語抄読会デッキにして。PICO、バイアスリスク、適用可能性を重視して。

PICOを先に固定。効果推定値は区間とともに読む。原資料がない確実性は、明示したまま残します。

学会発表

主要アウトカムはForestプロット、生存解析はKaplan–Meier、投影チェックを通るTable 1で。

決定論的チャート: 検証済みの1つのデータオブジェクトから幾何とラベルを導出。手配置の数値はありません。

症例カンファレンス

この匿名化メモから10分の症例カンファレンスデッキを作って。タイムライン、鑑別選択、明示した不確実性を入れて。

キーボード操作可能な選択コンポーネント。PHIの懸念があれば、議論ではなくビルドを停止します。

研修医向けの教育講演を作って。アルゴリズムとクイズ形式の確認問題を入れて。

アルゴリズム、チェックリスト、回答状態は、色に頼らず明示されます。

Safety

医学的事実を、捏造から守る。

エージェントが生成するすべてのデッキは、未検証の項目を未回答のまま開始します。Skill は不足した臨床的主張を補完せず、停止し、印をつけ、尋ねます。

  • 01

    PHIで停止

    識別子の可能性、DICOMメタデータ、画像への焼き込みテキストは、入力が匿名化されるまで生成を止めます。

  • 02

    主張の範囲を狭く保つ

    引用、DOI/PMID、ガイドライン版、統計は検証可能でなければなりません。分母や区間の矛盾は検出されます。

  • 03

    共有前は非公開のまま

    COI、倫理、同意、資金源は、提供されるまで未回答のままです。合成カタログのコンテンツは恒久的にマーカー付けされています。

ゲート 動作
PHI 患者識別情報の可能性がある場合に停止します。
引用 引用が検証できない場合、最終状態をブロックします。文献を捏造しません。
数値 分母、パーセント、単位、信頼区間、p値、フロー合計の矛盾を検出します。
COI・倫理 COIを「なし」に、倫理を「承認済み」に既定しません。
画像 来歴、ライセンス、同意、許可が不明な場合は使用を求めます。

Get started

次の発表に合わせて、Medical Slide を組み立てる。

ディレクトリ全体をインストールしてください。 SKILL.md だけをコピーしないでください。Skillにはエンジン、テーマ、参照資料、カタログが必要です。

01

リポジトリをクローン

git clone https://github.com/kgraph57/medical-slide-templates.git
cd medical-slide-templates
02

Claude Skill としてインストール

node scripts/install-skill.mjs --dest "$HOME/.claude/skills/medical-slide"
03

自然文で依頼する

# このRCT論文を、15分の日本語抄読会デッキにして。
# この匿名化メモから10分の英語症例カンファレンスデッキを作って。

Author

午前2時のスライド作業にうんざりした小児科医が作りました。

Medical Slide は、学会発表と抄読会のための個人ツールとして始まりました。医師が実際に行う発表を、実際の時間制約の中で作るためのツールです。

安全ゲートがあるのは、自信満々なシステムが生成する医療コンテンツが現実のリスクだからです。このプロジェクトは、不足した事実を補完するより、停止し、印をつけ、尋ねることを選びます。

岡本賢は小児科医であり、AI 医療起業家です。臨床実践と応用AIの交差点で、執筆・教育・ツール開発を行っています。
