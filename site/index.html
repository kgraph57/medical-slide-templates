Features

Built for the standards of an international conference, not a template gallery.

Deterministic medical charts

Forest plots, Kaplan–Meier curves, ROC, waterfall, and funnel charts derive geometry and labels from one validated data object. No hand-positioned values.

Choice components

Six native-HTML contracts for differentials, confidence scales, and decision options: keyboard-operable, print-safe, and meaningful without color.

Bilingual by design

Japanese and English are equal source languages. Natural clinical Japanese with word-break: auto-phrase; English preserves abbreviations, units, and drug names.

Fully offline

No web fonts, no CDN, no runtime dependencies. The bundled server binds to 127.0.0.1 and makes zero external requests (verified by automated tests).

Projection-legible

An enforced 18px floor for body and data text, checked at four viewport sizes with automated overflow detection and slide/PDF page parity.

Accessible output

Semantic headings, labeled figures, focus-visible controls, and axe scans with zero serious or critical violations in the test gate.

Safety gate

The Skill stops instead of completing missing medical facts.

This project creates clinician-facing academic and teaching presentations. It is not patient material, diagnosis, treatment selection, or clinical decision support.

Gate Behavior
PHI Stops and asks for corrected or de-identified input when patient-identifying information may be present, including DICOM metadata and burned-in image identifiers.
Citations Blocks final status when a citation, DOI, PMID, or guideline version cannot be verified. Never invents a reference.
Numbers Flags conflicts in denominators, percentages, units, confidence intervals, p values, and flow totals before preview.
COI / ethics Never defaults COI to none or ethics to approved. Unanswered required fields stay 未確認 / SOURCE NOT PROVIDED.
Images Asks for provenance, license, consent, or permission when image rights are unknown.
Synthetic content Every catalog and example slide carries a permanent visible marker and must never be reused as evidence.

Install

Install the complete directory: the Skill needs its engine, theme, and references.

01

Clone the repository

git clone https://github.com/kgraph57/medical-slide-templates.git
cd medical-slide-templates
02

Install as a Claude Skill

node scripts/install-skill.mjs --dest "$HOME/.claude/skills/medical-slide"
03

Ask in natural language

# このRCT論文を、15分の日本語抄読会スライドにして。
# Build a 10-minute English case-conference deck from these notes.
