## 監査所見（現行 Clinical Blue v1 の問題点）

1. **タイポグラフィの大小コントラスト不足** — タイトル 72px に対しラベル・メタが
   均質で、「キーノート的な大胆さ」がない。Duarte 流の主張見出しが埋もれる。
2. **アクセント色の多用** — 見出し下線、カード枠、テーブルヘッダー帯、stat 数字に
   まで青が使われ、色の意味が希釈されている。Tufte 的には色はデータのために温存する。
3. **表の行罫過剰** — 全行に下線がある現行は「教科書的」。NEJM 流 booktabs は
   上太線・ヘッダー下・下太線の3本のみ。
4. **余白が均質** — 全スライドが同じ密度で、余白による強弱（呼吸）がない。
5. **選択カードの枠が重い** — 2px グレー枠は機能的だが、世界水準の選択 UI は
   より静かで、選択状態の表現に階層がある。

## 導出された設計原則（v2）

1. **One slide, one assertion** — 見出しはトピック名ではなく主張文。
2. **Typographic contrast** — タイトル 80px 級 × メタ 12-13px 級。大小差 3 倍以上。
3. **Data-ink maximization** — 帯・罫線・枠を削り、インクをデータに集中する。
4. **Editorial restraint** — 表は booktabs 3本罫。色は意味のある箇所に限定。
5. **Quiet interaction** — 選択状態は静かだが明確に（インク太枠＋柔らかい地）。
6. **アクセント色の再定義** — 青は「キー数値・データ系列・小ラベル」のみ。
   大面積の青塗り（ヘッダー帯・ファネル頂点・比較ヘッダー）はインク色へ。

## 互換性の制約（変えてはいけないもの）

- 投影フロア: 本文・表・ラベル 18px 以上（テストで強制）
- オフライン: web フォント禁止、システムフォントスタックのみ
- コントラスト: axe serious/critical 違反 0
- 合成マーカー・ソース注記の表示契約
- 4 ビューポートで overflow 0
